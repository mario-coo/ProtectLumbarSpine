# 生图内容强制中文与医学可视化规范 (Image Generation & Visualization Rules)

> **最高优先级规则 (High Priority Constraint)**：
> 本项目为腰椎生物力学数字化健康知识库。所有多媒体图像与动态资产必须具备高度专业性、极简可读性与纯正中文标准。

---

## 一、 生图语言绝对红线 (Language Constraint)

1. **绝对禁止英文标注**：
   * 在本项目的所有任务中，任何 AI 生成的图像、解剖图解、受力分析图谱、工位坐姿示意图及动态 GIF，画面中的**标题、解剖结构指示、力学数值指标、卡尺标注与文字说明，一律严禁出现英文版，必须强制为中文版**。
   * 严禁生成包含如 `Annulus Fibrosus`、`Eye Level`、`Lumbar Support`、`Spasm` 等英文术语的最终交付图片。

2. **字体与排版工程化流水线 (Production Pipeline)**：
   * 鉴于扩散生图模型直接绘制中文字符易产生字形扭曲、拼写幻觉或笔画缺失，强制执行以下工程化工作流：
     1. **生图底模**：提示词中明确指示输出无文字、纯净的高精 3D 医学与解剖渲染图（Clean Render without text/labels）；
     2. **中文排版合成**：通过 Python (`scripts/` 目录下的排版脚本，基于 PIL / ImageDraw / ImageFont 加载标准系统字体如 `msyh.ttc` 微软雅黑），按医学解剖座标叠加抗锯齿中文专业标注、引线、玻璃拟态卡片与度量衡。
   * 确保所有输出图中的中文字迹锐利、间距优雅、符合出版级排版审美。

---

## 二、 临床医学与力学中文术语标准

解剖与力学标注必须严格遵照中国三甲医院骨科与放射科权威临床术语：
* `L5/S1 椎间盘`（不可缩写混淆）
* `纤维环` / `髓核` / `软骨终板`
* `硬脊膜囊` / `脑脊液`
* `S1 神经根`（受压充血水肿 / 正常通畅）
* `侧隐窝` / `椎间孔`
* `椎板` / `棘突` / `关节突小关节`
* `Batson 硬膜外静脉丛`
* `屈曲松弛现象 (FRP)` / `肌电静默`
* `粘弹性塑性蠕变 (Creep)`
* `Valsalva 屏气动作` / `腹内压 (IAP)`
